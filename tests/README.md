# Testing note

This starter ZIP does not claim to include an automated test suite. Before adding tests, manually verify:

1. The app starts and opens at http://127.0.0.1:5000.
2. The dashboard displays the fictional sample course, students and COs.
3. You can add a course, CO and student.
4. You can save marks from the Records page.
5. Saving a changed mark updates the dashboard attainment.

Record only tests you actually run in your project report / README.
